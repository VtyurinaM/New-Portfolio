# Портфолио — Втюрина Маргарита

Сайт-портфолио в формате кинематографичных слайдов: экраны сменяются прокруткой колёсика, переходы — видео.

## Как посмотреть у себя

Откройте `portfolio.html` двойным кликом. Всё работает и без интернета: шрифты, видео и работы лежат в папке `assets`.

## Как выложить на GitHub Pages

1. Зайдите на github.com → **New repository** → назовите, например, `portfolio` → **Public** → **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое** папки `portfolio-site` (не саму папку): `portfolio.html`, `README.md`, `.nojekyll` и папку `assets`.
   Веб-загрузка принимает до 100 файлов за раз. Если GitHub ругается, загрузите в два приёма: сначала всё, кроме `assets/projects`, потом папку `assets/projects`. Можно также воспользоваться программой GitHub Desktop.
3. Нажмите **Commit changes**.
4. **Settings → Pages → Branch: main → / (root) → Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/portfolio/portfolio.html`. Эту ссылку можно отправлять заказчикам.

## Что где менять

| Что | Файл |
| --- | --- |
| Тексты «обо мне», подпись к кольцу, навыки, FAQ, ссылки | `assets/js/data.js` |
| Названия и подписи проектов | `assets/js/data.js` → `projects` |
| Картинки проектов | `assets/projects/` (имена файлов описаны в `manifest.js`) |
| Цвета, размеры шрифтов | `assets/css/style.css` |

Чтобы добавить новую работу, проще всего положить её в исходную папку («иллюстрации» или «графический дизайн»), добавить строку в список в `prepare_projects.ps1`, снова запустить `prepare_projects.bat` и дописать название в `data.js`.

## Как устроено

- Экраны 1–10 — изображения из папки «экраны». Переходы между ними — видео из «видео с переходами», выровненные по экранам так, чтобы стоп-кадр и видео совпадали без скачка.
- Глаз на первом экране выбирает направление: карий — иллюстрации, голубой — графический дизайн. На экране с кольцом направление можно переключить внизу слева.
- Кольцо вращается стрелками на экране, клавишами ← →, перетаскиванием или горизонтальной прокруткой. Клик по передней карточке открывает проект, крестик возвращает к кольцу (обратное видео).
- FAQ открывается кнопкой в меню или скомканной бумажкой «FAQ». Назад — прокрутка вверх или «← к контактам».
- Повторная прокрутка во время перехода ускоряет видео.
